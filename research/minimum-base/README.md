# 両右辺の最小絶対値による有限排除

2026-11-27、GCC 14.2.0、Python 3.13.5 で B=5,000,000 および B=10,000,000 の計算を完走した。
対象は N=114514,364364、素数 p≥5、相互に素な非零整数 a,b,c。

**結果: 解が存在すれば min(|a|,|b|,|c|)>10,000,000。**
最大絶対値には上限を設けていない。ただし最小絶対値がこの値を超える解の不存在は未証明。
Lean による計算の認証も未実施。

## 再現

このディレクトリで実行する。C++17、Python 3 標準ライブラリを使用。
Python の assert は検査の一部なので -O を使用しないこと。
全工程が成功し、最後の12行で passed=0 であることを確認する。

```sh
set -e
B=10000000
g++ -O3 -std=c++17 -DBASE_BOUND=$B sieve.cpp -o sieve
./sieve > sieve_results.txt
python3 verify_remaining.py sieve_results.txt "$B" > supplemental_results.txt
g++ -O3 -std=c++17 certify_min.cpp -o certify_min
./certify_min "$B" > min_results.txt
sha256sum sieve_results.txt supplemental_results.txt min_results.txt
```

B=1000000 または 5000000 でも実行可能。sieve は B 以下の素数を全列挙し、
初回は q=kp+1 (k 偶数、2≤k≤108)、追加検査は 110≤k≤2000 の補助素数を調べる。
追加検査の assert が失敗した場合は6ケースへの帰着が成立していないので結論を出してはならない。
certify_min のオプション第2引数は指数を限定するためのものであり、全ケースの排除には指定しない。

## 数学的な完全性（B 以下の範囲について）

1. x≤y≤z を絶対値の順序とする。相互素性より z≥2 なら最大絶対値は一意。最大二項が同符号なら |和|≥z^p、異符号なら z^p−y^p≤x^p+N。
2. p≥19 のとき 2^p>N。x=1 なら z^p−y^p≥2^p−1 であり、和の絶対値が N を超える（全項の絶対値1も不可能）。2≤x≤p なら相互素性から y≥x+1,z≥y+1。二項定理で z^p−y^p≥p(x+1)^(p−1)>2x^p>x^p+N。中央の不等式は (p/x)(1+1/x)^(p−1)≥(1+1/p)^(p−1)>2 から従う。従って p<x。
3. p=5,7,11,13,17 の x≤p、さらに N=364364,p=5 の x≤17 を別途厳密検査する。x≤X のとき同符号なら z^p≤N。異符号なら (y+1)^p−y^p≤X^p+N から y の有限上限、さらに z^p≤y^p+X^p+N から z の有限上限を求め、順序付き絶対値と8通りの符号を全列挙する。verify_remaining.py に実装。
4. x≤B ならこれらの小指数の処理と p<x より、p≤B の検査で足りる。補助素数 q=kp+1 が素数なら非零 p 乗剰余は位数 k の部分群。相互素性により少なくとも二つの座標が単元なので、N が非零剰余2つと任意の剰余1つの和でない場合は全整数底について排除できる。
5. 残る (N,p) は (114514,7/19/31/67/317),(364364,5)。別途検査した小範囲以外では x^p>N と (p−1)x^(p−1)>N が成立する。最大二項は異符号で、差 d=z−y>0 と符号 s=±1 を用いて (y+d)^p−y^p=x^p+sN と書ける。差の因数分解により d|x^p+sN。二項定理で pd(x+1)^(p−1)≤x^p+sN<x(x+1)^(p−1)、従って pd<x。
6. 各 d≤floor((B−1)/p) について x^p≡−sN mod d の根を素数冪の根の持ち上げとCRTで列挙し、max(x_min,pd+1)≤x≤B にある全ての代表を検査する。根の総数を独立した公式で再検査し、重複がなく実際に合同式を満たすことを確認する。単元の根の個数は奇素数冪では巡回群の公式、2冪では奇数乗の自己同型による。非単元については v_q(N)<p より、目標が非零の非単元なら根なし、目標が0なら q^ceil(e/p) の倍数。
7. 各 (N,p,s,x,d) を、ある y mod q が差の合同式および相互素性を満たすことを必要とする複数のフィルタで検査。フィルタが1個でも失敗すればその候補は排除できる。密度の浮動小数点計算はフィルタの並べ替え・採用だけに使用され、候補の判定は整数演算のみ。passed>0 の場合は未排除であって具体解ではない。

## 残る問題

全指数を排除できる一様な上限、あるいは最小底に対する有効な一様上限を証明する必要がある。
有限範囲の計算の成功を無制限の不存在証明としない。
