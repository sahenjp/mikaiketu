# 研究ロードマップと監査

## 完了の定義

- 存在: 素数 p≥5、非零、相互素、等式を全て厳密な整数演算で検証した具体例を得る。
- 不存在: 全素数 p≥5、無制限の整数底を対象に証明する。
- Lean による証明はビルドと公理監査を通す。未解決命題を sorry、axiom、前提への埋め込みで済ませない。

## 既存手法の限界

- Fermat の最終定理は右辺0を扱う。N≠0の問題へ直接適用できない。
- Thue 方程式・Baker の線形形式・S-unit 方程式には、固定係数、固定体、固定素因数集合などの仮定がある。変動する x,y,z,p に必要な一様な仮定を示さない限り有効な上限を主張しない。
- Faltings の定理は種数2以上の曲線に関する定理で、この三変数方程式のアフィン曲面に直接適用できない。
- 射影化 a^p+b^p+c^p=Nw^p は対角曲面。元の問題は w=1 の整数点であり、射影有理点の存在と同じではない。
- Heath-Brown (2009) の表現数の上界は底の上限 B に依存する。B を超える解の不存在を意味しない。https://arxiv.org/abs/0806.4330
- p=7 の全法での局所可解性は docs/mathematics.md に証明を記載。通常の合同式を無限に増やす方針だけでは p=7 は排除できない。
- ABC の多項版を仮定しても、使用する正確な予想、部分和の非消滅条件、実効定数を確認する必要がある。特に低指数7に適用できるとは限らない。無条件の証明ではない。

## 過去のチャットの主張の扱い

過去の数値（指数50万、最小の底50万、最大の底100万等の探索結果、ヒルベルト記号の組数）は、当時の実行記録・独立再現性を確認していないため、ここでは証明として採用しない。

特に円分体のヒルベルト記号 (a+ζb,N) について、N を割らない全ての場所で記号が自動的に1になるという主張は一般には正しくない。a+ζb の素因数に対応する場所で、N の剰余が p 乗かを検討する必要がある。相互法則自体は大域積=1を述べるが、個別評価には別の計算が必要である。過去に挙げた組数は破棄し、再導出から始める。

また Hensel 持ち上げでは q|N の場合に c の偏微分が消えることがあるため、単元 a の偏微分で持ち上げる。p=7 の局所証明は修正版を記載した。

数学界での当該方程式の解決状況について網羅的な文献調査は完了していない。未解決問題としての登録や、既知の完全解答の不存在を主張しない。

## 実験の記録規則

計算ごとに Python/Lean のバージョン、コミット、コマンド、入力範囲、終了コード、出力を保存する。途中終了、タイムアウト、整数オーバーフロー、浮動小数点近似だけによる判定を「解なし」に分類しない。

新しい必要条件は、証明・独立した小規模全探索・境界値テストの3段階で監査する。追加候補は既存の証明と研究仮説を混同しないよう別節へ書く。
