# 数学的結果と証明

N=114514=2·31·1847。p は 5 以上の素数、底は非零整数で相互に素とする。この文書は元の問題の部分解であり、全体の不存在証明ではない。

## 1. 合同式による無条件の排除

q を素数とし、R={t^p mod q : t∈Z} とする。N mod q が R+R+R に含まれなければ、整数解は存在しない。底の上限や相互素性も不要である。

| p | q | R（負の代表元も使用） | N mod q |
|---:|---:|---|---:|
| 5 | 11 | 0, ±1 | 4 |
| 11 | 67 | 0, ±1, ±29, ±30 | 11 |
| 13 | 53 | 0, ±1, ±23 | 34 |
| 17 | 103 | 0, ±1, ±46, ±47 | 81 |
| 23 | 47 | 0, ±1 | 22 |
| 29 | 59 | 0, ±1 | 54 |

各行について三つの剰余の和を全列挙して確認できる。scripts/verify.py と tests/test_verify.py に独立検査を収録した。

一般に q=kp+1 が素数なら、非零 p 乗剰余は位数 k の部分群をなす。位数 k の h を一つ求め、R={0,1,h,…,h^(k−1)} とすれば q 個の底を列挙せずに済む。k の上限を設定した検査は、その範囲の補助素数しか扱わない。

また N が偶数なので、相互素性と合わせて a,b,c のうち **ちょうど一つが偶数** となる。

## 2. 符号の正規化と底の必要条件

絶対値を x≤y≤z と並べる。p は奇数なので、最大の二項が同符号なら絶対値は z^p 以上、異符号なら z^p−y^p ≤ x^p+N となる。

**命題: 解が存在すれば x>p、かつ 2≤x<y<z。**

証明:
- p=5,11,13 は第1節で排除済みなので、p=7 または p≥17 を扱う。
- p≥17 の同符号の場合、z≥2 なら z^p≥2^17>N。z=1 も不可能。
- p≥17、x=1 の場合、y=1 なら z≥2 に対して z^p−2>N。y≥2 なら相互素性により z>y であり、最大二項が異符号でも z^p−y^p≥3^p−2^p>N+1。
- p=7、x≤7 の場合、同符号なら z≤5。異符号なら z>y（等しい場合は相互素性から y=z=1 で全項の絶対値が1）。もし y≥8 なら z^7−y^7≥9^7−8^7>7^7+N で矛盾。よって y≤7、さらに z^7≤y^7+x^7+N≤2·7^7+N<8^7 より z≤7。区間 [−7,7] の全三つ組を検査すると解なし。
- 残る p≥17、2≤x≤p の場合、相互素性から y≥x+1、z≥y+1。二項定理により p(x+1)^(p−1)≤z^p−y^p≤x^p+N。
- しかし p(x+1)^(p−1)/x^p=(p/x)(1+1/x)^(p−1)≥(1+1/p)^(p−1)>2。最後の不等式は二項展開の最初の三項で示せる（p≥5）。
- x^p≥2^17>N なので x^p+N<2x^p となり矛盾。

したがって x>p。相互素性から絶対値は相異なり、同符号の最大二項も z^p>N のため不可能。□

よって任意の解は、順列を除けば s∈{−1,1} を用いて

    (a,b,c)=(-s*x,-s*y,s*z),
    z^p−y^p=x^p+s*N,
    p<x<y<z

と表せる。x>p≥7 なので x^p>N であり、両方の符号を検査する必要がある。

## 3. 冪の差による有限探索の完全性

d=z−y>0 とすると

    d | (x^p+s*N)
    p*d*(x+1)^(p−1) ≤ p*d*y^(p−1) ≤ x^p+s*N.

x>p≥7 より (p−1)x^(p−1)>N（最小値でも 6·8^6>N）。
二項展開で x(x+1)^(p−1)≥x^p+(p−1)x^(p−1)>x^p+N。
従って **p*d<x**。

最小の底の上限 B が与えられれば、p<B、p<x≤B、1≤d≤floor((x−1)/p) だけを調べればよい。各組について d が x^p+s*N を割らなければ除外する。

f(y)=(y+d)^p−y^p は正整数 y について狭義単調増加し、無限大に発散する。よって指数的な上限探索と二分探索で、事前に y,z の上限を仮定せずに解の有無を厳密に判定できる。

この計算は min(|a|,|b|,|c|)≤B の範囲について完全であり、B を除いた主張にはならない。Python 実装は標準ライブラリの整数演算だけを使用する。

## 4. 新たな因数分解・素因数制約

T=x^p+s*N、d=z−y、S=(z^p−y^p)/(z−y)=sum_{i=0}^{p−1} z^(p−1−i)y^i とする。T=d*S。

### 4.1 d と S の共通因子
gcd(y,z)=1 より gcd(y,d)=1。S≡p*y^(p−1) mod d なので

    gcd(d,S)=gcd(d,p)∈{1,p}.

p|d なら LTE により v_p(T)=v_p(d)+1、従って v_p(S)=1。
p∤d なら Fermat の小定理より T≡d mod p なので p∤T,S。

### 4.2 S の素因数の合同条件
素数 ℓ|S、ℓ≠p とする。ℓ∤d かつ ℓ∤y,z である。有限体 F_ℓ で z/y の位数は p（p 乗は1、元自体は1でない）。よって **ℓ≡1 mod p**。

従って S の素因数は、p が高々1回現れる場合を除けば全て 1 mod p。この条件に違反する T の素因数冪は d 側に吸収されなければならず、d<x/p という上限と矛盾する場合がある。

より正確に、T>0 の素因数分解から
D=product_{ℓ|T, ℓ≠p, ℓ≢1 (mod p)} ℓ^v_ℓ(T)
と置けば、D|d。p|T のときは v_p(T)≥2 が必要であり、p^(v_p(T)−1) も d を割る。
従って D およびこの p 因子を掛けた数が x/p 以上なら排除できる。T の完全因数分解は高コストだが、小素因数だけでも安全な下界フィルタになる。

### 4.3 N の平方因子がないことの利用
N=2·31·1847 は平方因子を持たない。ℓ|gcd(x,T) なら ℓ|N であり、p≥5 から v_ℓ(T)=1。従って gcd(x,T)|N、特に gcd(x,d)|N。

さらに p|N かつ p|x とすると v_p(T)=1 となるが、4.1 の必要条件に反する。よって p=31,1847 では p∤x かつ p∤d。

これらは数学的な必要条件であって、すべての x で矛盾することはまだ示されていない。

## 5. p=7 の強い局所条件

法29では R={0,±1,±12}、N≡22 であり、三つの剰余の和の解は (17,17,17) のみ。従って a,b,c の各々が mod 29 で {8,10,12,15,18,26,27} に属する。

特に 29 は a,b,c のいずれも割らず、a+b、b+c、c+a のいずれも割らない。第2節の符号正規化では 29∤d も従う。

## 6. p=7: 任意の法で相互に素な合同式解が存在

ここでは整数方程式そのものではなく、任意の正整数 m について a^7+b^7+c^7≡N (mod m) が相互素な非零整数で解けることを示す。

### 素数 q≠7, q≢1 mod 7
7 乗写像は F_q 上で全単射。a=1,b=−1 として c^7=N mod q を解く。仮に c が0でも a,b は非零。持ち上げには c ではなく、偏微分 7a^6 が単元である a を使用する。Hensel の補題で各 q^k に持ち上がり、少なくとも二座標が単元のまま保たれる。

### q=7
N≡1 mod49。x≡1 mod7 とし x^7≡N mod7^k (k≥2) が成立していれば
(x+7^(k−1)t)^7≡x^7+7^k*t mod7^(k+1)。
t を選んで帰納的に持ち上げる。(x,1,−1) が解で三座標とも単元。

### 素数 q≡1 mod7
q<1000 の28素数は scripts/verify.py local7 により、三座標が非零の合同式解を直接検査できる。

q≥1000 では曲線 X^7+Y^7=(N−1)Z^7 を F_q 上で考える。N−1=3·7²·19·41 なので q∤7(N−1)。よって非特異な平面7次曲線、種数15。非特異な平面曲線は幾何学的既約であり、Hasse–Weil の下界 q+1−30sqrt(q)>21 が成立する。各座標が0の点は高々7個、合計高々21個。従って全座標非零の点が存在する。

Z=1 に正規化して (a,b,1) を得る。この曲線は存在証明に使う補助曲線であり、小さな q の全解を c=1 に制限する必要はない。任意の q^k へは a の偏微分が非零なので Hensel で持ち上げる。

### 合成数と相互素性
中国剰余定理で各 q^k の解を統合。m を割る素数については、同時に二座標が0になることはない。m を割らない素数について、まず非零の整数代表 a を一つ選び、次に b の代表を a の有限個の素因数（m を割らないもの）を避けるよう CRT で選ぶ。最後に c について a*b の素因数を同様に避ける。代表は非零にできる。

以上で任意の m について合同式解が得られる。□

**帰結:** p=7 は通常の有限個の合同式による矛盾だけでは排除できない。ただしこれは整数解の存在を意味しない。異なる法における相互法則・大域的障害まで否定するものでもない。
