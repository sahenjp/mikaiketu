# 両右辺の共通研究ノート

## 証明済みの初等的事実

N=114514=2·31·1847、364364=4·49·11·169。p は奇素数なので、符号の反転と順列を利用できる。N は偶数で相互素性よりちょうど一つの底が偶数。

p=5,N=114514: mod 11 の五乗剰余は 0,±1 であり N≡4。
p=7,N=364364: mod 29 の七乗剰余は 0,±1,±12 であり N≡8。三項の和に8は現れない。
p=7,N=114514: mod 29 では三項とも17でなければならない。

### 最小底による探索の一般化

x≤y≤z を絶対値の順序とする。x≥2 なら相互素性から x<y<z。最大二項が異符号なら z^p−y^p≤x^p+N。最大二項が同符号なら |和|≥z^p。x=1 でも z≥2 なら y<z（y=z≥2 は相互素性に反する）。

p≥19 では 2^p>N。x=1 は z^p−y^p≥2^p−1>N+1 により排除（y=z=1 も不可能）。2≤x≤p とすると
p(x+1)^(p−1)>2x^p>x^p+N。
前半は (p/x)(1+1/x)^(p−1)≥(1+1/p)^(p−1)>2（二項展開の最初の三項）から従う。従って x>p。

小指数 p=5,7,11,13,17 は別途有限検査する。x≤p なら最大二項が異符号の場合 y≥p+1 で (p+2)^p−(p+1)^p>p^p+N が成立するか確認し、成立する場合 y≤p、z^p≤2p^p+N となる。成立しない場合も y の上限は単調な差 (y+1)^p−y^p から求められる。scripts/two_targets.py で両右辺についてこの有限検査を実装する。

x>p かつ x^p>N なら最大二項は異符号で、z^p−y^p=x^p±N。d=z−y>0 と置く。d|x^p±N、p*d*y^(p−1)≤x^p±N。さらに (p−1)x^(p−1)>N なら p*d<x。低指数でこの条件が成立しない小さな x は一般の二項下界で別処理する。固定 x,p に対し y の上限を仮定せず、d≤(x^p+N)/(p*(x+1)^(p−1)) と単調二分探索で判定できる。

### 因数分解と付値

T=x^p±N=d*S, S=Σ z^(p−1−i)y^i。gcd(y,z)=1 より gcd(d,S)=gcd(d,p)。素数 ℓ|S, ℓ≠p なら ℓ≡1 mod p（z/y の位数が p）。p|d なら v_p(S)=1 (LTE)、p∤d なら p∤S。
よって p≠ℓ かつ ℓ≢1 mod p の素因数冪はすべて d に入る。p|T なら v_p(T)≥2 が必要。
両 N の各素因数の付値は p 未満なので ℓ|x,N なら v_ℓ(T)=v_ℓ(N)。特に p|N, v_p(N)=1 の場合 p∤x。364364 の p=7,13 では v_p(N)=2 なので同じ排除はできない。

## 局所可解性と今後の方針

候補 (N,p)=(114514,7/19/31/67/317),(364364,5) の法 p² の解は独立に検査可能。q≠p で少なくとも二座標が単元なら、単元座標の偏微分で Hensel 持ち上げ可能。q=p では p² の単元解を二項展開で持ち上げる。任意の法への結論には全素数 q の確認と CRT が必要。単なる有限個の確認を全法の証明とは呼ばない。

次の研究: 有効な指数上限、円分体での素因数制約と大域障害、最小底を上限とする厳密探索、証明証明書の Lean 化。固定指数の点数評価を全整数解の上限に読み替えない。

## 計算記録と監査

2026-11-27 に会話添付の C++ 3プログラムを再実行。p≤100000, q=kp+1, 偶数 k≤108 で 9590 素数を検査し、相互素性を考慮した候補は上記6件。最大絶対値100000以下について6件とも解0。これは既存添付の再実行記録であり、リポジトリ内の Python スクリプトの実行結果とは区別する。p≥100000 かつ M=max|a,b,c|≤100000 なら M≥2 のとき M^p−2(M−1)^p≥M^p(1−2/e)>N。M=1 も不可能。従ってこの最大底範囲では全指数を排除する。

以前の回答の局所証明には修正が必要: N−1≡0 mod q の場合 (1,1,−1) は和1となるので正しいが、q=p の単元条件は必ず確認する。Hasse–Weil の適用には係数非零が必要。Jacobi 和評価は q|N の場合を別扱いすること。過去の法29の剰余一覧や数値例は必ず機械的に再検査する。未検証の Lean コードは形式証明済みと表示しない。
