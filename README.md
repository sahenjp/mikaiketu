# 114514 のディオファントス方程式

素数 p ≥ 5、非零整数 a,b,c が相互に素であるとき

```text
a^p + b^p + c^p = 114514
gcd(a,b) = gcd(b,c) = gcd(c,a) = 1
```

を満たす解が存在するか。底・指数ともに上限を仮定しない。

## 再現方法

```sh
python3 -m unittest discover -s tests -v
python3 scripts/verify.py local7
python3 scripts/verify.py sieve --bound 10000 --max-k 200
python3 scripts/verify.py search --bound 1000 --max-k 200
```

search の上限は最大の底ではなく **最小の絶対値**。他の底の上限は数学的に導出する。計算が終了した範囲だけを排除できる。sieve で残った指数は「解が存在する指数」ではなく「選択した法で排除されなかった指数」。
